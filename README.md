# e-plantShopping
  
  **Paradise Nursery** — aplicação de carrinho de compras para uma loja online de plantas de interior (houseplants), desenvolvida como projeto final do curso
  *Developing Front-End Apps with React*.
  
  ## Visão Geral
  
  Repositório: **e-plantShopping**
  
  A aplicação permite ao usuário navegar por uma variedade de plantas de interior, visualizar detalhes (imagem, nome, descrição e preço) e gerenciar um
  carrinho de compras com atualização dinâmica de quantidades e cálculo do custo total.
  
  ## Páginas
  
  - **Landing page** — apresentação da empresa, imagem de fundo, nome da loja e botão *Get Started*.
  - **Product listing page** — catálogo de plantas agrupadas por categoria, com botão *Add to Cart* e navbar com o total de itens no carrinho.
  - **Shopping cart page** — itens adicionados, com ajuste de quantidade (aumentar/diminuir), exclusão, subtotais, custo total e botão de checkout.
  
  ## Tecnologias
  
  - React (function components + hooks)
  - Redux Toolkit (gerenciamento do estado do carrinho via slice)
  - React Redux
  - Vite (build e dev server)
